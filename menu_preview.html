Design notes:
• Eclipse uses ┏━┓ rounded boxes with ⟢ bullets, lowercase cryptic tone
• Astraea uses ╔═╗ double-line boxes with ☀ bullets, UPPERCASE divine tone
• Each menu has: header art → opening poem (6 lines) → command boxes → closing poem → stats footer
• Command boxes group related commands with descriptions that wrap 2-3 lines
• *bold* renders as WhatsApp bold in the actual message
